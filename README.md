# CSE 4114 Lab-01 — Bike Sharing Data Analysis

Authentic UCI Bike Sharing hourly data analysis. Exactly 2,000 valid observations were selected from the uploaded `hour.csv` dataset using reproducible `random_state=42`; no synthetic rows were added.

## 8 selected columns
season, mnth, holiday, workingday, temp, hum, windspeed, cnt

`cnt` is the total bike rental count and is used as the main outcome for analysis.
